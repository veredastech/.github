# .github

Arquivos padrão da organização: templates de Pull Request e de issue, e o guia de contribuição. O GitHub usa este repositório como **default** para qualquer repo da organização que não tenha os seus próprios.

Este repositório é **público** por exigência do GitHub — os arquivos de *community health* só valem para toda a organização se o `.github` for público. O conteúdo aqui é genérico de processo: convenções de commit, branch, changelog e documentação. Nada de cliente, projeto ou dado entra neste repositório.

O override é **total, não merge**: um `ISSUE_TEMPLATE/` dentro de um repositório anula este default por inteiro, não item a item.
